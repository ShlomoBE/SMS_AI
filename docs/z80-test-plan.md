# Z80 independent QA test plan

**Status:** independent test strategy; the architecture direction is approved and partial CPU implementation and xUnit tests now exist. The project targets .NET 10; detailed CPU signatures and variant remain open. The first tier is instruction-stepped and approximate in intra-instruction time; it must not be marketed as cycle accurate.

## Evidence and fixture policy

- **[Z]** Zilog, [Z80 CPU User Manual UM008011-0816](https://www.zilog.com/docs/z80/um0080.pdf), particularly instruction descriptions, instruction summary, flag tables, timing diagrams and interrupt response. The manual is copyrighted; link to it, do not copy or redistribute it. Resolve apparent manual contradictions against an identified chip and independent evidence; do not silently generate expected results from the implementation.
- **[S]** [SingleStepTests/z80](https://github.com/SingleStepTests/z80), JSON pre/post states and bus cycles, generated from a translated Ares-derived core, not a hardware oracle. Its [LICENSE](https://raw.githubusercontent.com/SingleStepTests/z80/main/LICENSE) is MIT, copyright 2024 SingleStepTests; retain copyright and permission notice when copying substantial portions. Verify individual fixture provenance and exact revision before import. Compare against [Z] and other evidence, especially hidden state and I/O; differences are investigations, not automatic CPU failures.
- Seven partial numeric records from [revision `ebe1875d48f374bcfd4b505d8eb8ee751568b5f7`](https://github.com/SingleStepTests/z80/commit/ebe1875d48f374bcfd4b505d8eb8ee751568b5f7) are asserted in `Z80ExternalRotateVectorsTests`; see its comments and the adjacent MIT license. The first (`0000`) record was selected from each of `v1/cb 00.json`, `cb 08.json`, `cb 10.json`, `cb 18.json`, `cb 20.json`, `cb 28.json` and `cb 38.json`. Only B, F, R, PC and aggregate cycle count were transcribed; other source fields were intentionally omitted and remain unverified. They cover one register encoding per rotate/shift family, not full machine state or physical hardware. Its memory `BIT` vectors derive undocumented F3/F5 from hidden WZ; current CPU state cannot yet inject WZ. Until an approved state seam exists, those comparisons are blocked or must clearly report partial documented-flag assertions. Preserve complete source fields and provenance with future bulk fixture imports.
- **[X]** Frank Cringle's [ZEXDOC/ZEXALL source and README](https://github.com/agn453/ZEXALL): source header says GPL version 2 or later; repository [LICENSE](https://github.com/agn453/ZEXALL/blob/main/LICENSE) contains GPL v2 and README describes GPL v2. ZEXDOC exercises documented flags; ZEXALL includes undocumented bits. Treat the specific selected source/artifact's notice as authoritative; review redistribution obligations before use. Optional separate CP/M-style harness, no binary imported under this task. Neither exerciser is complete interrupt, timing, or opcode coverage; source explicitly avoids HALT.
- **[U]** Sean Young, *The Undocumented Z80 Documented*, local `IDocs/z80-documented.pdf`; supplementary research, not proof for the SMS CPU revision. Undocumented flag bits 3/5, MEMPTR/WZ, Q, prefixes and silicon quirks require variant-scoped corroboration. SMS interrupt and bus hypotheses are in `hardware-assumptions.md` and Charles MacDonald's `IDocs/General.txt` §5. A Zilog Z80 is a useful baseline, not proof every SMS integrates identical silicon.

For every imported fixture record upstream URL, commit, file/hash, license and notice, generator/target, local modifications and expected coverage; pin and audit before use. Do not commit BIOS, commercial ROMs or other unlicensed test assets. Public access alone is not a license. Cross-check representative results with [Z], and variant-dependent results with independent real-chip evidence when available. Capture conflicts with repro and source, never silently mask them.

## Harness and assertions

After the lead freezes an interface, build a deterministic C#/.NET test adapter around the CPU, not around a production SMS mapper. Arrange full register/alternate banks, PC/SP, I/R, flags, IFFs, IM, HALT and EI delay; initialize relevant memory and scripted I/O/acknowledge; execute a defined instruction or repeat iteration; assert complete state, changed and unchanged memory, total T-states and ordered fetch/read/write/I/O/ack transactions. Log actual port16 and byte order. Assert preserved flags using both initial flag polarities. Use explicit seed and bounded execution; print initial state, bytes, source vector ID, expected/actual state and first divergent transaction on failure. Fresh fixture per case, no host clock or random global state.

Some vector fields (WZ, Q, P and refresh pin details) are not promised by v0.1. Do not invent a public API: use a lead-approved test seam or black-box observable sequences; classify unsupported observations as blocked. Likewise, a step's handling of an entire block repeat, HALT or interrupts must be specified before comparing individual transitions. Tests injecting asynchronous edges or WAIT in the middle of a step require the future resumable interface; do not simulate precision the adapter cannot observe.

## Decode and opcode-space coverage

Generate a checked-in, independently reviewed manifest from [Z] plus separately labeled [U]/[S] entries, not from the decoder under test. Each entry contains encoded prefix context and final opcode, documented/undocumented/undefined classification, target profile, required operands/conditions and oracle references. Exercise every manifest entry, including operand/register aliases; do not equate mnemonic counts with byte coverage.

| Space / generated cases | Required distinctions and risks |
| --- | --- |
| Unprefixed `00`–`FF` | All terminal opcodes, including `76` HALT; treat `CB`, `DD`, `ED`, `FD` as prefix transitions, not standalone completed instructions. Immediate bytes and branch outcomes varied independently. |
| `CB xx` | All 256 final bytes: all eight register/(HL) fields, eight bit positions and all rotate/shift groups. Separate documented instructions from SLL/SL1. |
| `ED xx` | Classify all 256 final bytes; all documented loads, 16-bit ALU, NEG, IM, RETN/RETI, I/O, nibble and block forms. Alias/undefined behavior gets its own variant evidence and explicit status, not assumed NOP. |
| `DD xx`, `FD xx` | Inventory all 256 following bytes per prefix, including meaningful IX/IY substitutions, ignored prefixes and transitions to other prefix spaces. Test index high/low undocumented forms and H/L versus index-half exceptions with indexed memory. Prefix chains are separate from terminal coverage. |
| `DD CB d xx`, `FD CB d xx` | All 256 final bytes per index; signed displacement, memory target, BIT versus modifying forms; register-copy encodings and SLL labeled undocumented. Do not assume opcode/displacement fetch types. |
| Prefix sequences | Repeated DD/FD in both orders, longer chains, DD/FD before ED, DD/FD before unaffected instruction, and PC wrap between every prefix/displacement/opcode/operand. Last-prefix and ignored-prefix behavior must be confirmed per selected variant. Bound chain lengths in CI; arbitrary length is not exhaustively testable. |

Report per space and classification **executed and asserted entries / eligible terminal manifest entries**, with a separate count of prefix transitions. An entry counts only if a test asserts independently sourced expected architectural state and total time, plus applicable ordered bus effects; a decoder hit or skipped/unverified case is not coverage. Keep excluded/undefined and blocked counts visible and justified, never hide them from totals. Separate percentages for documented and variant-dependent spaces; publish missing byte IDs, not just an aggregate. Also report branch-outcome, flag-transition, operand-boundary, timing-path and interrupt-scenario coverage as required/covered/blocked; one opcode case is not exhaustive semantic coverage. Initial values: **0 covered, manifest not yet built, denominator not yet established**.

## Instruction and flag matrix

For each row generate every legal addressing/operand form from the manifest; use [Z] per-instruction flags and timing, with [S] as independently implemented differential data. For each case check PC advance, unaffected registers/flags and all bus actions, not just destination. Flags are S, Z, H, P/V, N, C; bits 3/5 are a separate variant tier.

| Family | Practical cases and required assertions |
| --- | --- |
| 8-bit loads | Register/register, immediate, `(HL)`, `(BC)`, `(DE)`, absolute and indexed reads/writes; test zero, FF, asymmetric values, address FFFF wrap, self-load and source/destination alias. Special I/R transfers with both IFF2 values; flag preservation and documented flag changes by form. |
| 16-bit loads, stack, exchange | BC/DE/HL/SP/IX/IY immediate and absolute forms; PUSH/POP all pairs including AF, EX AF,AF', EXX, EX DE,HL and EX (SP),HL/IX/IY; distinctive bytes, SP near 0000/FFFF, byte order, overlap with code/stack and flag preservation. |
| 8-bit ADD/ADC/SUB/SBC/CP | Exhaust all 256×256 operand pairs and both carry inputs where applicable; cover register, immediate, memory and index forms via representative cross-product plus all encodings. Assert result or CP no-write and each documented flag. Specifically half carry/borrow, carry/borrow, signed overflow, zero and sign transitions. |
| INC/DEC 8-bit | All 256 inputs and both incoming C values, each register and memory/index form; preserve C, cover overflow and nibble boundary; read-modify-write order. |
| AND/XOR/OR | All 256×256 operand pairs against independent truth tables; parity versus arithmetic overflow, H/N/C constants per [Z], S/Z; all forms via manifest. |
| 16-bit ADD, ADC, SBC, INC, DEC | All register-pair forms including SP and both index registers; cross 0000, 0001, 0FFF, 1000, 7FFF, 8000, FFFF with both carry inputs where applicable. Check word carry, half carry, signed overflow, and preserved flags per instruction; 16-bit INC/DEC do not reuse 8-bit flag rules. |
| DAA, CPL, SCF, CCF, NEG | For DAA enumerate A=00–FF and all incoming N/H/C combinations with an independently verified table, separating reachable BCD from arbitrary state. Exercise chains after add/subtract. CPL/SCF/CCF use both starting values of all flags; NEG all 256 operands, especially 00 and 80. Variant-sensitive undocumented flags/Q isolated. |
| RLCA/RRCA/RLA/RRA; CB RLC/RRC/RL/RR/SLA/SRA/SRL | Exhaust byte inputs and carry-in 0/1 for each operation; every register, `(HL)` and indexed encoding; test shifted-out bits, sign retention and carry insertion. Compare accumulator forms' preserved S/Z/PV against CB forms' computed flags. SLL/SL1 is a separately sourced undocumented group. |
| BIT/SET/RES | Each bit 0–7 × byte 0–255 × register/(HL)/IX+d/IY+d; C preservation for BIT, all documented flags unchanged for SET/RES, no BIT write, correct read-modify-write for others. Indexed register-copy aliases only if supported by variant evidence; bit 3/5 sources need separate oracle. |
| RLD/RRD | All 16 accumulator low-nibble × 256 memory-byte combinations, with representative accumulator high nibbles; preserve accumulator high nibble and C; verify memory read/write and S/Z/parity/H/N. Use more values for unchanged flags and address wrap. |
| JP/JR/DJNZ/CALL/RET/RST | All conditions true and false with both polarities, including relative displacements -128, -1, 0, +127 and PC wrap. DJNZ initial B=00,01,02,FF. CALL/RET/RST stack order, return address and wrapping SP; conditional no-write path; JP indirect forms. |
| Block transfer/search | LDI/LDD/LDIR/LDDR and CPI/CPD/CPIR/CPDR: BC 0000/0001/0002/FFFF, address wrap, overlapping source/destination, matching first/middle/last/no byte, each direction. Assert flags, PC, count, ordered accesses and final versus repeating iteration time; sample INT/NMI between repeats in cycle-capable tier. Bound BC=0 repetition. |
| I/O and block I/O | IN/OUT immediate and `(C)` forms; INI/IND/INIR/INDR/OUTI/OUTD/OTIR/OTDR. Use distinct upper/lower port bytes, B=00/01/02/FF, direction and memory wrap, distinctive returned values, flags and final/repeat paths. Check port address and register update order against [Z] and corroborated vectors; isolate undocumented flags. No SMS low-byte masking in generic CPU tests. |
| Control and reset | NOP, DI, EI, HALT, IM 0/1/2, RETN/RETI and I/R instructions; state transitions and unaffected flags. Test RESET only for documented effects; test deterministic fixture initialization separately from physical power-on. RETI bus signaling, if exposed, needs an approved contract. |

Use algebraic properties as supplements, never as the sole oracle: reversible EX twice, PUSH/POP with non-overlapping memory, rotations through all positions, SET/RES idempotence, CP equivalence to subtraction flags, and paired block transfers. Explicitly test input/output aliasing and side effects so a duplicate read cannot pass by yielding the same byte.

## Timing, bus and refresh matrix

Reference **T-states**, not machine cycles or SMS master ticks, against the relevant [Z] instruction table; fixture values include prefixes and taken/not-taken or repeat/terminal paths. For each manifest encoding verify base total, including conditional JP/JR/DJNZ/CALL/RET both outcomes, indexed displacement operations, block repeat/final, stack, I/O and each interrupt mode. Use [S] totals as a second source but do not compare its per-pin traces to an instruction-step implementation.

| Scenario | Assertions / limitations |
| --- | --- |
| Fetch and operands | Ordered fetch versus data read identities, immediate/displacement order and PC wrapping. Distinguish opcode M1 fetch from other reads where interface permits; no invented intra-instruction timestamps. |
| Stack / word accesses | Byte order for push/pop/call/return/exchange and 16-bit memory transfers, with wrap and side-effecting bus; no merged word operation. |
| I/O | Full 16-bit port and ordered memory/I/O accesses; independent bus returns scripted values and records each call. No duplicate reads. |
| R refresh | Initialize R near low-seven-bit rollover with high bit both values; compare increments for opcode/prefix fetches, HALT and interrupt acknowledge against applicable evidence; LD R,A and LD A,R separately. Refresh pins and exact phases require later bus-cycle tier. |
| HALT | PC/state after entry, repeated idle time/fetch effects, no ordinary next-instruction execution, accepted interrupt exit and return address. Distinguish asserted but disabled INT from accepted interrupt. |
| WAIT | Later cycle tier: inject at each eligible bus phase, vary duration, check only relevant operation stretches and subsequent event ordering; no unstated fixed waits. Instruction tier: mark blocked, not passing. |
| Access-time interactions | Later cycle tier: accesses adjacent to device events, equal-time ordering and split versus continuous execution. Contract policy and hardware phase remain unresolved; flag as blocked, never assert approximate timestamps as hardware. |

## Interrupt scenario matrix

Drive explicit boundary schedules and assert PC, SP, IFF1/IFF2, IM, delayed EI, HALT, ordered stack/ack transactions and total response T-states against [Z]. Model INT as a persistent level and NMI as an edge-latched input. In instruction tier inject only at defined boundaries; within-instruction timing is blocked. Check IRQ source remains asserted until its device clears it in later integration tests.

| Case | Stimulus and observation |
| --- | --- |
| DI and INT | INT held with IFF1 clear: no acceptance; DI after enabled state clears enables. INT withdrawn before an eligible sample must not become a latched interrupt. |
| EI delay | Hold INT across EI and following instruction; compare acceptance only after the protected instruction. Exercise EI;EI, EI;DI, EI;HALT, and INT deassertion before acceptance against [Z] plus variant evidence for corner cases. |
| NMI edge and priority | Edge with IFFs both states, retained/high NMI without repeated edges, deassert then reassert, simultaneous eligible INT and NMI; assert NMI priority, correct stack/PC and IFF effects from [Z]. Explore pending second edge and EI interaction as variant-sensitive cases; do not invent outcomes. |
| Return | NMI followed by RETN with IFF2 both values; RETI separately. Test nested NMI and IFF interactions against verified target evidence, not an assumed IFF2 update. |
| IM 0 | Vary acknowledge byte, beginning with single-byte RST then other bus-supplied opcodes only once bus delivery semantics are specified; verify ack, side effects, PC/stack and response time. Multi-byte IM 0 requires explicit bus contract and evidence. |
| IM 1 | Acknowledge and vector to documented fixed handler, stack order and saved return PC; held INT after return/re-enable, not cleared by ack. |
| IM 2 | Distinct I and ack bytes; table word read order, pointer page/end-of-address-space wrap, odd and even ack values. Manual prescribes an even vector; odd byte behavior and SMS-reported FF are separately gated on target evidence, not silently masked. |
| HALT exit | INT disabled versus enabled, and NMI; assert response PC/stack and elapsed idle plus response T-states separately. |
| Repeat instructions | Inject INT/NMI at inter-iteration sampling points during repeating transfer/search/I/O; save return PC and resume correctly. Block until step granularity and sampling are observable. |

## Gates and known gaps

1. **Before broad CPU testing:** lead selects chip/profile, defines complete test state injection, exact step/interrupt boundary semantics and expected support policy for undocumented/undefined encodings. Ask for a contract change if required, rather than modifying a shared interface unilaterally.
2. **Fast CI:** deterministic targeted cases for each instruction family, documented flag edge cases, branch outcomes, bus ordering, interrupt boundary regressions and per-space manifest reporting. All supported documented entries must have at least one independently asserted case, and every required scenario must be covered or explicitly blocked. No passing status while a required regression fails.
3. **Extended CI:** exhaustive finite 8-bit arithmetic/shift cases, all documented manifest entries, full pinned [S] import after license/provenance review, optional separately acquired [X] under approved licensing and CP/M harness. Report duration, timeouts and skips; a timeout is not a pass. Verify reports from the exercised target, not another emulator's published result.
4. **Future cycle tier:** run timestamped bus, WAIT and interrupt-phase cases with a resumable interface and validated phase policy. Compare external traces only to the selected CPU profile. Until then, ordered instruction-level transactions and totals establish neither bus-cycle accuracy nor SMS game compatibility.

Coverage deliberately remains open for arbitrary prefix lengths, exhaustive 16-bit operand pairs, all device event alignments and every silicon revision. Undocumented flags, WZ/Q, undefined EDs, interrupt races and SMS CPU identity need further evidence. Licensed fixture availability does not establish that it is correct or hardware-derived. No third-party binaries or ROMs have been imported.
